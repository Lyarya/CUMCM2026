# Q1 储能物理参数灵敏度

## 可复现入口与范围

运行 `python src/problem1/sensitivity.py`。直接调用已验证的 `solve_deterministic_dispatch`，
不修改 `src/problem1/model.py`、原始目标函数、互斥变量或约束形式。
只有指定物理参数改变；全年数据、预测、不确定性及Q2/Q3/Q4调度均不参与。
所有输入及受保护文件的SHA-256保存在 `results/problem1/tables/q1_sensitivity_audit.json`。

## 设置与单位

- 效率：单程充电效率和单程放电效率同时为0.80/0.85/0.90/0.95，往返效率为两者乘积。
- 容量：6000/9000/12000/15000 kWh；SOC限值随容量保持10%—90%，首末均为50%；功率保持5000 kW。
- 功率：2500/3750/5000/6250 kW；容量12000 kWh，其余参数固定。
- 充放电量采用交流母线侧能量（功率除以6），不能误认为电池内部能量。
- SOC最小/最大值遍历145个边界状态，同时报告kWh及容量百分比。
- 12个表格情形含3次相同的基准配置，共10个独立MILP求解；基准重复行复用同一解。

## 接受规则

全部情形须为Optimal，数值有限、144个时段齐全；功率平衡、电量递推、跨时段状态连续、
首末电量、SOC上下界、功率上限、充放电互斥、非负购电、非负充放电与0≤弃光≤PV均须通过。
沿用Q1验证器的1e-3数值容差（对应量的kW/kWh/元），额外核验能量列等于功率/6。
任一失败会中止输出，而不是丢弃失败点后继续发布成功子集。

## 基准核验

保存的基准成本为35126.948591235元，无储能对照为48052.046590847元。
复算的目标值、购电/充电/放电/弃光总量与保存结果一致。
CBC可在相同价格时段选择不同的等价最优充电时序，复算与已存轨迹的最大购电/充电功率差为2000 kW、
最大储电量差为300 kWh。保存轨迹也独立通过原约束检验。
因此基准核验以原文件hash、目标值、总量和物理可行性为准，不额外加入择优规则以强迫轨迹逐点相同；
原 `result1.xlsx`、调度CSV与基准图均保持不变。

## 解释口径

容量的三个等步长扩容收益约2850.82/2042.64/1570.20元；
功率的三个等步长扩容收益约1043.97/219.92/53.93元，均观察到边际递减。
0.80到0.95的单程效率提高使成本下降约11.66%。
比较“主导参数”时不能直接比较不等宽扫参区间的总成本变化；
采用基准到相邻更高设定的成本相对下降除以参数相对增加，
效率/容量/功率约为0.697/0.179/0.006。按此定义效率最敏感，容量仍有经济作用，
当前功率上限接近该日需求下的收益饱和区域。
这是有限差分结果，不是严格局部导数；效率与另两类参数的步长不同，也不是投资回报分析。
