# 问题三调整购电结算规则审计

## 官方文字证据

题目第 2 页问题 3 原文规定：可根据 00:00 预报制定计划购电策略，并可根据其他时刻预报“调整购电策略”；计划购电量高于调整购电量的部分按交易时刻电价的 50% 计违约电价，调整购电量高于计划购电量的超出部分按交易时刻电价的 1.5 倍计价。附件 5 又分别要求保存“根据 0:00 预报制定的计划购电量”和“根据其他预报制定的调整购电量”。证据来源：`C题.pdf` 第 2--3 页，问题 3 与附件 5 的 `result3.xlsx` 说明。

## 判定

```text
official_rule_classification = AMBIGUOUS
```

官方文字明确了单次“计划量—调整量”差额的价格，却没有明确 12:00 或 18:00 的再次调整应相对于前一次承诺，还是始终相对于 00:00 原始计划结算。因此当前阶段不得静默选择。

接口 `src/problem3/information_schedule.py::adjustment_settlement(...)` 同时支持：

- `SEQUENTIAL_PREVIOUS_COMMITMENT`：每次修订相对于前一次承诺结算；
- `ORIGINAL_00_COMMITMENT`：最终修订相对于 00:00 原始承诺结算。

两种模式均使用

```text
C_adjust = 1.5 * p * delta_plus - 0.5 * p * delta_minus
```

且原始 00:00 计划购电量仍按全额 `p*g^(0)` 计费。待赛事官方答疑或队伍作出明确建模假设后，再锁定一种约定并进行经济计算。
