# Stage 2B：Q2 期望成本随机 MILP 检查点

本检查点只实现问题二的第一版期望成本随机 MILP，不含 CVaR、风险参数扫描、问题三或问题四。
优化器只通过 `src/problem2/forecast_interface.py::get_q2_day_inputs` 读取冻结的点预测、50 个
成对负荷/光伏场景、固定电价和调用方传入的初始储能电量。负荷场景与光伏场景始终使用共同的
场景索引，没有分别重排或重新抽样。

对每个运营日，计划购电、充电、放电、充放电模式和储能电量是 0:00 确定的场景共享变量；
场景变量增加“实际调用的计划购电”。它满足 `0 <= planned_grid_used <= planned_grid`，未调用部分
仍按日前计划付费；光伏弃电则保持独立变量且不超过该场景可用光伏。各场景满足功率平衡，紧急
购电非负并按当时普通电价的 5 倍计费。该修正消除了旧模型把全部计划电强塞入每个场景、从而
迫使计划量受最低负荷场景限制的问题。

问题二没有沿用问题一的硬约束 `E_start = E_end = 6000`。为防止逐日有限视界在最后时段放空，
同时避免围绕日初电量的对称惩罚造成每日能量中性，模型采用三段边际价值递减的跨日延续价值。
第一断点由 50 个场景相对点预测的正向净负荷误差能量的 80% 分位数确定，第二断点位于第一断点
与最大储能量的中点，第三断点为最大储能量；三段价值率由当日电价的 90%、50%、10% 分位数
乘放电效率确定。该延续价值只用于优化，不计入实际成本。

实际回放将计划充放电作为动作上限，并在实际可消纳功率或 SOC 边界使计划动作不可行时向下
裁剪。实际 SOC 使用实际动作递推，第二天的初始电量取前一天的实际日末电量。正式结果跨日
最大衔接误差为 0，实际 SOC 范围为 1200--10800 kWh，全年最终储能量为 7834.330 kWh。

完整期为 2025-02-01 至 2025-12-31，共 334 天。所有日期均由 PuLP 调用 HiGHS 得到
`Optimal` 状态；程序遇到任一非最优状态会立即停止。机器可读结果位于
`results/problem2/tables/`，包括逐日汇总、48096 行逐时段计划以及包含完整场景紧急购电和弃光
数组，以及场景实际调用/未使用计划购电数组的压缩 NPZ。官方模板结果写入
`results/problem2/result2.xlsx`。

模型中的场景紧急购电用于 0:00 计划优化；正式执行结果则在计划固定后使用附件 2 的实际负荷
和实际光伏计算。`result2.xlsx` 的“紧急购电量”工作表填写实际紧急购电，不再填写场景均值；
每个运营日均保留全部 144 个 10 分钟时段，包括紧急购电量为零的时段。时间标签与官方计划
购电表头一致：第 1 格为 `0:10-0:20`，末格为 `0:00-0:10+1`。
论文表 3 仅选取题面指定的 2025.3.20、2025.6.21、2025.9.23 和 2025.12.21，并严格采用
每个日期下“时间段、购电量”两列的横向分组形式。正文展示前 6 个时段并以省略号说明，完整
144 时段数据写入附件。对应机器可读文件为
`table_p2_table3_emergency.csv`，LaTeX 表为 `table_p2_table3_emergency.tex`。

334 天均为 `Optimal`。累计计划购电量为 21793145.183 kWh，计划购电费为 13323201.223 元；
场景期望紧急购电费为 1051144.023 元，期望运营成本为 14374345.246 元。实际紧急购电量为
398161.901 kWh，紧急购电费为 1516260.779 元，实际总成本为 14839462.002 元。逐时输出中
不再存在未吸收放电或其他无物理解释的能量汇。本检查点不引入 CVaR。
